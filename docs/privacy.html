プライバシーポリシー

最終更新: 2026-08-24

YAE View は、利用者の個人情報を収集しません。 利用状況の記録、解析、広告のための仕組みは一切入っていません。 開いたファイルの中身が制作者や第三者へ送られることもありません。

収集しないもの

YAE View は次のいずれも行いません。

  • 氏名・メールアドレス・住所などの個人情報の入力を求めること
  • アカウントの作成やサインイン
  • 利用状況・操作履歴・不具合情報の外部への送信
  • 開いたファイルやその一覧の外部への送信
  • 広告の表示、および広告のための識別子の利用

端末の中に保存されるもの

アプリの動作に必要なデータは、すべて利用者の端末の中だけに保存されます。 外部へは送られません。

  • %APPDATA%\YaeView\projects.json — プロジェクト（開いたファイルのパスと並び）
  • %APPDATA%\YaeView\annotations.json — 手書きメモ・しおり
  • %APPDATA%\YaeView\annotation-assets\ — メモに貼り付けた画像
  • %APPDATA%\YaeView\config.json — アプリの設定
  • %APPDATA%\YaeView\window_state.json — 窓の大きさと位置
  • %APPDATA%\YaeView\logs\ — 起動と異常の記録（ファイルの中身は含みません）
  • %LOCALAPPDATA% の下 — 表示を速くするための縮小画像。消しても中身は失われません

これらを削除するには、アプリを終了してから上記のフォルダを削除してください。 アンインストールしても自動では消えません。

開いたファイルの扱い

画像・動画・PDF などのファイルは、表示のために読み取るだけです。 利用者が保存や書き出しを指示したときを除き、書き換えることはありません。 ファイルの中身がアプリの外へ出ることはありません。

ネットワークを使う場面

YAE View がネットワークに触れるのは、次の場合だけです。

1. 別の端末との共有（利用者が開始したときだけ）

  • 「別の端末と共有」を実行している間だけ、同じネットワーク内にファイルを配信します
  • 配信先は同一ネットワーク内に限られます。インターネットへは公開されません
  • URL には推測しにくい文字列が含まれ、共有を終了すると無効になります
  • 制作者を含む第三者のサーバーは経由しません

2. 更新の確認

  • 公式サイトからダウンロードした版は、新しい版があるかを GitHub に問い合わせます
  • 送信されるのは現在のバージョン番号だけです。個人情報は含まれません
  • Microsoft Store 版はこの機能を持ちません。更新はストアが行います

3. ヘルプ画面のリンク

  • 押すと既定のブラウザで公式サイトが開きます。アプリからの送信はありません

第三者への提供

収集しているものが無いため、第三者へ提供するデータもありません。 データの販売・共有・分析委託のいずれも行いません。

お子さまの利用について

YAE View は年齢に関する情報を収集しません。 特定の年齢層を対象とした機能や、そのための情報収集も行いません。

同梱しているソフトウェア

YAE View には ImageMagick、pdf.js などの他者のソフトウェアが含まれています。 いずれも端末内で動作し、外部へ通信するようには使用していません。 著作権表示とライセンス本文は、ヘルプ画面の「このアプリについて」から確認できます。

変更について

このポリシーを変更した場合は、このページの最終更新日を改めます。 重要な変更があるときは、リリースノートにも記載します。
