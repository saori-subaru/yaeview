Privacy Policy

Last updated: 2026-08-24

YAE View does not collect personal data. It contains no analytics, telemetry, or advertising. The contents of the files you open are never sent to the developer or to anyone else.

What we do not collect

YAE View never does any of the following.

  • Ask for your name, email address, postal address, or similar details
  • Create an account or ask you to sign in
  • Send usage data, activity history, or crash reports anywhere
  • Send the files you open, or a list of them, anywhere
  • Show advertising, or use advertising identifiers

What is stored on your device

Everything the app needs is stored only on your own device. None of it is transmitted.

  • %APPDATA%\YaeView\projects.json — your projects (file paths and their arrangement)
  • %APPDATA%\YaeView\annotations.json — annotations and bookmarks
  • %APPDATA%\YaeView\annotation-assets\ — images pasted into annotations
  • %APPDATA%\YaeView\config.json — application settings
  • %APPDATA%\YaeView\window_state.json — window size and position
  • %APPDATA%\YaeView\logs\ — startup and error records (no file contents)
  • Under %LOCALAPPDATA% — shrunken copies used to make lists load fast. Deleting them loses nothing.

To remove this data, close the app and delete the folders above. Uninstalling does not delete them automatically.

How your files are handled

Images, videos, PDFs, and other files are read only in order to display them. They are never modified unless you explicitly save or export. Their contents never leave the application.

When the network is used

YAE View touches the network only in these situations.

1. Sharing with another device (only while you start it)

  • Files are served only while you are running "Share with another device"
  • They are reachable only within the same local network, never published to the internet
  • The URL contains a hard-to-guess token, and stops working when you end sharing
  • No third-party server is involved, including the developer's

2. Checking for updates

  • Builds downloaded from the website ask GitHub whether a newer version exists
  • Only the current version number is sent. No personal data is included.
  • The Microsoft Store version has no such feature. The Store handles updates.

3. Links in the Help screen

  • These open the website in your default browser. The app itself sends nothing.

Sharing with third parties

Because nothing is collected, there is nothing to share. We do not sell, share, or outsource the analysis of any data.

Children

YAE View does not collect any information about age, and has no features directed at a particular age group, nor collection for that purpose.

Bundled software

YAE View includes third-party software such as ImageMagick and pdf.js. All of it runs locally, and none of it is used in a way that communicates externally. Copyright notices and license texts are available from "About this app" in the Help screen.

Changes

If this policy changes, the date at the top of this page is updated. Significant changes are also noted in the release notes.

Contact

Questions about this policy are welcome at support@yaeview.com.
