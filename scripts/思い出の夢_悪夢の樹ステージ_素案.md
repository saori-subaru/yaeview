# 思い出の夢：悪夢の樹ステージ 台本素案

> **状態:** 素案（v0.1）
> キャラクター名・固有名詞は未確定のためプレースホルダー表記（【主人公】【あの人】など）。
> お菓子ステージ素案（`思い出の夢_お菓子ステージ_素案.md`）と対になる構成です。

---

## 1. コンセプト

- 悪夢の樹は「封じ込めた記憶が根を張って育ったもの」。恐ろしいのは樹ではなく、見ないふりをしてきた記憶そのもの。
- 思い出の中心は **「【あの人】と最後に会った日、言えなかった言葉」**。
- お菓子ステージの思い出（約束・苺・飴玉）と同じ記憶の「裏側」を描く。甘い記憶と痛い記憶は同じ一日につながっている、という構造。
- テーマカラー：藍色・墨色・枯枝の茶。思い出の核心部のみ、雨のガラス越しの灰色。

## 2. 登場人物

| 表記 | 役割 | 備考 |
|---|---|---|
| 【主人公】 | 夢を旅する主人公 | プレイヤーキャラ |
| 【あの人】 | 思い出の中の大切な人 | お菓子ステージと同一人物 |
| 【相棒】 | 夢の中の案内役・同行者 | 不要なら削除可 |
| 悪夢の樹（声） | 封じた記憶の具現 | 【主人公】自身の声で演じる案あり |

## 3. シーン構成

1. **導入** — 悪夢の樹の根元。幹のうろが扉になっている。【相棒】が初めて「行かない」選択肢を口にする。
2. **思い出①（雨の日）** — 【あの人】との別れの日。幼い【主人公】は約束のお菓子を持って行けなかった。
3. **思い出②（言えなかった言葉）** — 病室（または別れの場面）。幼い【主人公】は何も言えずに背を向けてしまう。
4. **対峙** — 悪夢の樹の声＝自分を責め続けてきた自分の声。飴玉（お菓子ステージのキーアイテム）が応える。
5. **帰還** — 樹は枯れず、白い花をひとつ咲かせる。悪夢は消えるのではなく、思い出に還る。

## 4. 台本

### S1. 導入

```
（悪夢の樹の根元。黒い幹のうろが、ちょうど扉のかたちに開いている）

【相棒】「……ここだけは、無理に入らなくてもいいんだよ」
【主人公】「（首を横に振る）」
【相棒】「……そう。じゃあ、これだけ約束して。中で何を見ても、目をそらさないこと」

（うろに足を踏み入れると、雨の音が聞こえてくる）
```

### S2. 思い出①（雨の日）

```
（雨の日の玄関先。幼い【主人公】が包みを抱えて立ちすくんでいる。
　包みの中身は、苺をのせたクッキー——あの日の約束のお菓子）

大人の声（遠く）「……今日は、もう行かないと」
幼い【主人公】「でも、やっと上手に焼けたのに。まだ渡してないのに」

（雨が強くなる。包みを抱えたまま、車が出ていくのを見送る）
```

### S3. 思い出②（言えなかった言葉）

```
（白い部屋。ベッドの【あの人】。幼い【主人公】は入口から動けない）

【あの人】「……来てくれたの。こっちにおいで」
幼い【主人公】「（一歩も動けない）」
【あの人】「……いいのよ。怖いよね。ごめんね」

（幼い【主人公】は、何も言えないまま背を向けて走り出してしまう。
　廊下に、包みが落ちる音）

幼い【主人公】（モノローグ）「言いたかったのに。約束のお菓子、できたよって。
　　　　　　　　　　　　　　……ずっと一緒にいてって。それだけだったのに」
```

### S4. 対峙

```
（景色が墨に沈み、悪夢の樹の内部へ。枝の軋む音が、声になる）

悪夢の樹「おまえは渡せなかった」
悪夢の樹「おまえは逃げた。最後のときに、背を向けた」
【主人公】「……っ」
悪夢の樹「だから忘れようとした。わたしを、ここに埋めた」

（【主人公】、うつむく——そのとき、ポケットの飴玉が淡く光る）

【あの人】の声「約束はまだ、なくなってないよ」

【主人公】「（顔を上げて）……ごめん。ずっと、目をそらしてて、ごめん」
【主人公】「でも、忘れたかったんじゃない。忘れたくなかったから、痛かったんだ」

（悪夢の樹の軋みが、ゆっくりと止む）

悪夢の樹「……ならば、わたしを覚えていられるか。この痛みごと」
【主人公】「（うなずく）……うん。ぜんぶ、わたしの思い出だから」
```

### S5. 帰還

```
（樹のうろの外。見上げると、黒い枝の先に白い花がひとつ咲いている）

【相棒】「……枯らさなかったんだね」
【主人公】「（うなずく）」
【相棒】「悪夢っていうのはさ、消しちゃえば楽なんだよ。でも——」
【相棒】「思い出に還してやれるのは、ちゃんと痛がった奴だけだ。……よく頑張った」

（風。白い花びらが一枚、飴玉の隣にそっと落ちる）
```

## 5. 演出メモ

- S2〜S3の思い出パートは彩度を落とし、雨音を環境音として常時流す。
- 悪夢の樹の声は【主人公】と同じ声質（エコー加工）にすると「自責の声」であることが伝わる。
- S4の飴玉の光と【あの人】の声で、お菓子ステージのS4（飴玉を渡す場面）を短くフラッシュバックさせる。
- クリア後、お菓子ステージに再訪すると悪夢の樹の白い花が一輪咲いている……などのクロス演出も検討可。
