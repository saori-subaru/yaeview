# 思い出の夢：お菓子ステージ 台本素案

> **状態:** 素案（v0.1）
> キャラクター名・固有名詞は未確定のためプレースホルダー表記（【主人公】【あの人】など）。
> 世界観設定が確定し次第、差し替えてください。

---

## 1. コンセプト

- お菓子ステージは「幸せだった記憶が結晶化した夢」。甘く、暖かく、少しだけ切ない。
- 思い出の中心は **「【あの人】と一緒にお菓子を作った日」**。
- ステージの明るさと対比するように、思い出の終盤で「その日々がもう戻らないこと」を静かに示唆する。
- テーマカラー：クリーム色・苺色・キャラメル色。終盤のみ夕暮れのオレンジへ。

## 2. 登場人物

| 表記 | 役割 | 備考 |
|---|---|---|
| 【主人公】 | 夢を旅する主人公 | プレイヤーキャラ |
| 【あの人】 | 思い出の中の大切な人（母・祖母・姉など想定） | 続柄は設定確定後に決定 |
| 【相棒】 | 夢の中の案内役・同行者 | 不要なら削除可 |

## 3. シーン構成

1. **導入** — ステージ最奥、巨大なホールケーキの上の扉。開けると白い光。
2. **思い出①（台所）** — 幼い【主人公】と【あの人】がお菓子を作る。失敗して笑い合う。
3. **思い出②（約束）** — 「今度はもっと上手に作ろうね」という小さな約束。
4. **覚醒の予兆** — 夕暮れ。台所の風景が砂糖菓子のように崩れ始める。
5. **帰還** — ステージに戻る。手の中にひとつだけ飴玉（キーアイテム候補）が残っている。

## 4. 台本

### S1. 導入

```
（ステージ最奥。巨大なホールケーキの頂上に、粉砂糖をまとった小さな扉）

【相棒】「……この匂い、覚えがあるんじゃない？」
【主人公】「（うなずく）」
【相棒】「行っておいでよ。ここは、あんたの甘い方の記憶だ」

（扉を開けると、白い光があふれる）
```

### S2. 思い出①（台所）

```
（暖かい台所。オーブンの音。幼い【主人公】が踏み台の上でボウルを混ぜている）

【あの人】「ほら、そんなに急いで混ぜたら粉が飛んじゃうよ」
幼い【主人公】「だって、はやく食べたいんだもん」
【あの人】「ふふ。お菓子はね、待つ時間もぜんぶ美味しさのうちなの」

（オーブンを開けると、焦げたクッキー。ふたりで顔を見合わせる）

幼い【主人公】「……まっくろ」
【あの人】「あはは！　いいのいいの。真っ黒でも、二人で作ったんだから世界一」

（ふたりの笑い声。画面が柔らかくにじむ）
```

### S3. 思い出②（約束）

```
（窓の外は夕方。焦げたクッキーをかじりながら）

幼い【主人公】「ねえ、今度はぜったい上手に作ろうね」
【あの人】「うん、約束。……次は、苺をのせようか」
幼い【主人公】「ゆびきり！」

（小指を結ぶふたり。その手元だけがやけに鮮明に描かれる）
```

### S4. 覚醒の予兆

```
（夕暮れの色が濃くなる。台所の輪郭が、砂糖細工のように端から崩れていく）

幼い【主人公】「【あの人】……？」
【あの人】「（振り向いて、微笑む）……ちゃんと、覚えててくれたんだね」
【あの人】「約束はまだ、なくなってないよ。ここに置いておくから」

（【あの人】が手のひらに小さな飴玉をのせてくれる。光がすべてを包む）
```

### S5. 帰還

```
（お菓子ステージ。扉の前。【主人公】の手の中に飴玉がひとつ）

【相棒】「……おかえり。いい夢だった？」
【主人公】「（飴玉を握りしめて、うなずく）」
【相棒】「そっか。……ほら、行こう。次は、あんまり甘くない夢かもしれないけどさ」
```

## 5. 演出メモ

- 思い出パートは画面の四隅を白くぼかし、「記憶の中」であることを示す。
- BGMはオルゴール調。S4で同じメロディをピアノのスローテンポに変化させる。
- 「焦げたクッキー」「苺」「飴玉」は悪夢の樹ステージの台本と対応させ、伏線として再利用可能。
