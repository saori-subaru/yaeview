# Yae View

画像・動画・PDFを並べて確かめる、Windows用のビューアです。

**→ https://saori-subaru.github.io/yaeview/**

## ダウンロード

[最新版のリリース](https://github.com/saori-subaru/yaeview/releases/latest)から
`YAEView_<バージョン>_x64-setup.exe` を取得してください。

Windows 10 / 11（64bit）専用です。Mac と Linux には対応していません。

インストール時に「WindowsによってPCが保護されました」と出た場合は、
**詳細情報 → 実行** の順に押してください。開発元の署名を付けていないために出る警告です。

更新はアプリが自分で受け取ります。入れ直す必要はありません。

## 不具合・要望

[サイトのフォーム](https://saori-subaru.github.io/yaeview/#report)から送れます。
アプリのヘルプ画面から開くと、バージョンなどが自動で入ります。

## このリポジトリについて

配布専用です。インストーラの配信、自動更新の確認先、
および公開ページ（`docs/`）を置いています。アプリのソースは含みません。
